# Compy classroom pack 1

Small programs for a Compy classroom. Each folder is one Compy project.

| Program | What it is |
| --- | --- |
| `ball` | A bouncing ball: change its size, speed and color. |
| `matrix` | A 10 by 10 grid: change the rule that colors each square. |
| `myart` | A white circle on a black screen, drawn in five lines. |
| `shapesticker` | Pictures made of circles, half and quarter circles, triangles, squares and half squares, as drawn on grid paper: `dofile 'one.lua'` draws the first. |

## Run

Start a program in Compy with its name:

```lua
run("ball")
```
